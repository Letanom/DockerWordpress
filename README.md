# WordPress Docker Compose

Bu proje, Docker ve Docker Compose kullanarak WordPress ve MySQL veritabanı içeren bir ortamı hızlıca kurmanıza olanak tanır. Kendi blogunuzu veya web sitenizi kurmak için gereksinim duyduğunuz tüm servisleri içerir.

## Başlarken

Aşağıdaki adımları takip ederek WordPress'i hızlıca çalıştırabilirsiniz.

### Gereksinimler

- Docker
- Docker Compose

Eğer bu araçlar sisteminizde kurulu değilse, [Docker'ı buradan indirebilirsiniz](https://www.docker.com/get-started).
